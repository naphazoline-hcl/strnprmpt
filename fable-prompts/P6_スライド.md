## 【最重要】聴衆の前提知識と説明方針（本プロンプトの設計思想）

- **聴衆ペルソナ**:
  - 審査員・聴衆は**「数理情報（確率論・応用統計・最適化理論・情報数理など）に精通している大学教授陣」**である。
  - 数理的思考力・論理的厳密さには極めて長けているが、**「強化学習（RL）」や「分布型強化学習（Distributional RL）」の専門家ではない**。
- **説明方針の厳格ルール**:
  1. **強化学習の文脈から必然性を丁寧に語る**:
     - いきなり特定タスク（金融ヘッジ等）の枝葉に入らない。
     - 「通常の強化学習（期待値最大化）では破産・クラッシュ等の壊滅的損失（リスク）を評価・回避できない $\to$ リターンの確率分布全体を捉える分布型強化学習が必要」という動機を明確に示すこと。
  2. **CVaR（条件付きバリューアットリスク）の意義と直感を伝える**:
     - 数式だけでなく、「最悪 $\alpha$（下位5%等）の極端損失領域における条件付き期待値」であり、高安全性制御や金融リスク管理の標準尺度であることを明快に伝えること。
  3. **マニアックなRL手法年表（C51, QR-DQN等）の禁止**:
     - C51やQR-DQNなどのRL専門用語の年表羅列は聴衆の理解を妨げるため**厳禁**。
     - あくまで「連続な分位点関数 $F^{-1}(\tau)$ を有限個の代表点（原子・分位点値）で離散近似（最適量子化）する数理的問題」として説明すること。
  4. **既存FQFの革新性と構造的欠陥を対比する**:
     - FQFは確率の区切り位置（quantile fraction $\tau_i$）自体を適応学習する代表的枠組みである。
     - しかし、一様重み付き1-Wasserstein距離 $W_1$ を最小化するため、代表点が全体に均等分散し、下側裾 $[0, \alpha]$（$N=16, \alpha=0.05$）に原子がほぼゼロ個（$16 \times 0.05 = 0.8 < 1$）になる致命的欠陥があることを浮き彫りにすること。
  5. **提案手法の数理的必然性を際立たせる**:
     - CVaR推定誤差が「歪み分布どうしの1-Wasserstein距離 $W_1(g_\# Z, g_\# \hat{Z})$」で厳密に上界付けられる定理を示し、「一様 $W_1$ を歪み重み付き $W_1$ に置き換える」ことが数学的に最も自然かつ強力な解法であることを納得させること。

1. **タイトル**

   - 副題：卒業研究 中間発表

2. **背景①：強化学習における「リスク」と分布型RLの必要性**
   - 左右2カラムまたは上下ブロック構成：
     - `\begin{block}{通常の強化学習（期待値最大化）とその限界}`:
       - 目的関数: 期待リターン $\mathbb{E}[Z(s,a)]$ の最大化。
       - 限界: 平均値のみを評価するため、**「平均収益は高いが稀に破産・大事故を起こす方策」**を回避できない（金融・自動運転等での致命傷）。
     - `\begin{exampleblock}{分布型強化学習（Distributional RL）の登場}`:
       - スカラーの期待値ではなく、リターンの**確率分布（確率変数 $Z(s,a)$）そのものを学習・表現**する枠組み。
       - 分布全体を捉えることで、確率分布の下側裾に着目した**「リスク感応型意思決定（Risk-Sensitive RL）」**が可能になる！

3. **背景②：目標リスク尺度「CVaR」と下側裾の重要性**
   - 左右2カラム構成：
     - 左列（数式と定義）：
       - `\begin{block}{条件付きバリューアットリスク（CVaR）}`:
         $$\CVaR_\alpha(Z) = \mathbb{E}[Z \mid Z \le F^{-1}(\alpha)] = \frac{1}{\alpha}\int_0^\alpha F^{-1}(\tau)\,d\tau$$
         最悪 $\alpha$（下位5%等）の極端損失領域における条件付き期待値。
       - 金融（デルタヘッジ）や安全工学において、壊滅的損失を防ぐ標準的なコヒーレントリスク尺度。
     - 右列（TikZ図解＋課題提示）：
       - 確率密度関数の下側裾（$[0, \alpha]$ 領域）を網掛けし、$\Finv(\alpha)$ を明示した TikZ 図。
       - `\begin{alertblock}{本質的な課題}`:
         CVaRを正確に評価・最適化するには、分布の大部分（通常領域）ではなく、**「下側裾 $[0, \alpha]$」の解像度（近似精度）が死活問題**となる！

4. **既存手法の限界：FQFと「一様量子化」の罠**
   - 左右2カラム構成：
     - 左列（FQF概要図 `fig1_fqf_overview.png`）：
       - FQF（Yang et al., 2019）の仕組み：状態 $\to$ FPNが quantile fraction $\tau_i$ を提案 $\to$ 分位点値ネットワークが分位点値を出力。
       - **特長**: 分位点値だけでなく、**確率の区切り位置（quantile fraction $\tau_i$）自体を適応学習する代表的手法**。
     - 右列（数式と致命的欠陥）：
       - `\begin{alertblock}{FQFの目的関数：一様重み付き1-Wasserstein距離}`:
         $$W_1(Z, \hat{Z}) = \int_0^1 \bigl|\Finv(\tau) - \Fhinv(\tau)\bigr|\,d\tau$$
       - **致命的欠陥**: 全体を均等に良く近似しようとするため、代表点 $\tau_i$ が $[0, 1]$ 全体に均等分散する。
       - $\alpha=0.05, N=16$ のとき、下側裾 $[0, \alpha]$ に割り振られる原子は **平均 $16 \times 0.05 = 0.8 < 1$ 個（ほぼゼロ個）**！
       - $\to$ **下側裾の解像度が完全に不足し、CVaR推定誤差が莫大になる！**

5. **提案手法の着想：歪みリスク尺度と1-Wasserstein誤差上界**
   - 数理的架け橋と主定理：
     - `\begin{block}{歪みリスク尺度としてのCVaR}`:
       - 歪み関数 $g(\tau) = \min(\tau/\alpha, 1)$ を用いると、$\CVaR_\alpha(Z) = \int_0^1 \Finv(\tau)\,dg(\tau)$ と表現できる。
       - その導関数は $g'(\tau) = 1/\alpha$（$\tau < \alpha$）、$g'(\tau) = 0$（$\tau > \alpha$）。
     - `\begin{exampleblock}{核心となる誤差上界定理（数理的必然性）}`:
       $$|\CVaR_\alpha(Z) - \CVaR_\alpha(\hat{Z})| \le \int_0^1 g'(\tau)\,\bigl|\Finv(\tau) - \Fhinv(\tau)\bigr|\,d\tau = W_1(g_\# Z,\,g_\# \hat{Z})$$
       CVaR推定誤差は、**歪み分布 $g_\# Z$ と $g_\# \hat{Z}$ の間の1-Wasserstein距離で厳密に上から抑えられる**！
     - **結論**: 一様 $W_1$ ではなく、**「歪み重み付き1-Wasserstein距離 $W_1(g_\# Z, g_\# \hat{Z})$」を目的関数として quantile fraction を学習すれば、CVaR誤差を直接最小化できる！**

6. **提案手法：歪み重み付きFQFの定式化と勾配**
   - 左右2カラムまたはブロック構成：
     - `\begin{block}{提案目的関数 $L_g$}`:
       $$L_g = W_1(g_\# Z,\,g_\# \hat{Z}) = \sum_{i=0}^{N-1}\int_{\tau_i}^{\tau_{i+1}}\bigl|\Finv(\tau) - \Finv(\hat{\tau}_i)\bigr|\,g'(\tau)\,d\tau$$
       原子 $\hat{\tau}_i$ は各区間の $g$-中央値に配置する。
     - `\begin{exampleblock}{主定理：quantile fractionに関する勾配（閉形式）}`:
       $$\frac{\partial L_g}{\partial \tau_i} = g'(\tau_i) \left[ 2\Finv(\tau_i) - \Finv(\hat{\tau}_i) - \Finv(\hat{\tau}_{i-1}) \right]$$
     - **数理的・実装的美しさ**:
       - 従来のFQFの勾配に、**歪み関数の微分 $g'(\tau_i)$（裾で $1/\alpha$、それ以外で $0$）を乗じるのみ**！
       - 下側裾にある区切り点には $1/\alpha$（20倍）の強い勾配が働き、通常領域の点は動かさない。
       - quantile fraction が自動的に下側裾 $[0, \alpha]$ へ引き寄せられ集中する！

7. **新規性と先行研究との位置づけ**
   - 左右2カラムまたは表形式による明確な対比：
     - `\begin{block}{先行研究のアプローチ（読み出し側・値側の変更）}`:
       - **IQN** (Dabney et al., 2018): サンプリング側で $\tau \sim U(0,1)$ を歪めるのみ。分位点配置自体は学習しない。
       - **Beyond CVaR** (ICML 2025): 分位点「値」に重みを与えるが、区切り位置 $\tau_i$ は一様固定。
       - **Tail-Safe** (Zhang, 2025): 読み出し時のサンプリングを下側裾へヒューリスティックに傾斜させるのみ。
     - `\begin{exampleblock}{本研究の独自性（損失側・最適量子化アプローチ）}`:
       - **「損失関数（学習側）において、Wasserstein誤差上界に基づいて quantile fraction 配置自体を歪み分布の最適1次元量子化として学習する」** 新たなアプローチ。

## 用語・表記ルール（中間レポートS4改稿版と完全一致させること）
- **quantile fraction**: $\tau_i$ の呼称は英語のまま使う。初出で「quantile fraction（累積確率軸 $[0, 1]$ の区切り位置）」と定義し、以降は英語のまま（「下側裾quantile fraction数」等）。quantile単体の意味では「分位点〜」（分位点関数・分位点回帰）。「分数」は不可（「分数勾配」も廃止。「quantile fractionに関する勾配」または「境界勾配」を使う）。分布の裾は「下側裾」に統一し「尾部」「左尾」「テール」は使わない。
- **原子（アトム）**／**サポート**／**コサイン基底**（余弦基底不可）／**損益**（P&L 不可）／**オラクル禁止**（真の分位点関数／CVaR最適静的方策／最適値 を使う）／**有限サンプル設定 A-fs**（変種 不可）。
- 英語の用語名の直後に日本語の説明を続けるときは句点「.」を使う（「。」は入れない）。

## 実験数値（確定実数値・この値のみを使用すること）
- **実験A（$\alpha=0.05, N=16$）**:
  - D1 ガウス混合: 一様 $0.309 \to$ 歪み最適 $0.00316$（改善比 $R = 97.9$）
  - D2 負の対数正規: 一様 $2.12 \to$ 歪み最適 $0.0404$（改善比 $R = 52.4$）
  - D3 Student-$t$ ($\nu=3$): 一様 $0.974 \to$ 歪み最適 $0.0246$（改善比 $R = 39.6$）
  - 判定基準 $R \ge 2$ は全分布で PASS。
  - 歪み最適配置は15個の内部 quantile fraction のうち13個を下側裾 $[0,\alpha]$ に配置（一様は0個）。
  - 点数換算値（N-equivalence）: 歪み最適16点 $\approx$ 一様695点（$\alpha=0.05$）。
  - $\alpha N \ge 2$ 領域の最小 $R = 42.3$、log-log傾き約 $-1.8$。
- **実験B（100kステップ・3シード mean±SD）**:
  - M-est MAE（全110対）: B0 FQF $= 7.02 \pm 0.11$ ／ B1 歪みFQF $= 1.41 \pm 0.75$（約 $1/5$ に低減） ／ B2 IQN $= 0.36 \pm 0.04$。
  - M-est MAE（意思決定状態）: B0 $= 14.41$ ／ B1 $= 3.24$ ／ B2 $= 0.15$。
  - 下側裾 quantile fraction 数（状態あたり）: B1 $= 0.48 \pm 0.38$（B0 $= 0$）。
  - M-pol CVaR（参考値）: B2 $= 1.01 \pm 0.01$（最適値 $1.0043$ に最接近） ＞ B1 $= -1.15 \pm 1.94$ ＞ B0 $= -10.79 \pm 0.00$。
