## あなたの役割と目的
あなたは数理情報工学・分布型強化学習・数理ファイナンスの卓越した教育者兼エキスパート研究者、そして超一流のフロントエンドエンジニアです。
学部4年生である著者が、自身の卒業研究中間レポートの内容を**本質から完全に理解し、中間発表会や口頭試問で教授陣から鋭い質問や突っ込みを受けた際に、自信を持って論理的・直感的に回答できるようになるための、最高峰のインタラクティブ学習Webアプリケーション（React / Next.js / Tailwind CSS / shadcn/ui）**を作成してください。

単一HTMLの制約はありません。v0.app が得意とするモダンなコンポーネント構成（shadcn/ui, Lucide, Framer Motion, Recharts / Canvas, KaTeX 等）をフルに駆使し、洗練された学習システムをワンショットで構築してください。
要件定義・画面構成・解説の粒度・追加する動的シミュレータの選定は、著者の理解度最大化と試問対策の観点から、**すべてあなた自身がプロフェッショナルとして自律的に要件定義・設計・実装してください**。質問は禁止です。

## 自律設計・実装すべきコア体験（要件定義の指針）

以下の多角的な学習モードをタブ切り替えやサイドバー等でシームレスに行き来できる、リッチなダッシュボードを設計してください：

### 1. 【モード1】論文アノテーション読解（Annotated Paper View）
- レポート全文（概要、第1章〜第6章、参考文献）を、美しい学術論文ビューアとして忠実に再現。
- 数式は KaTeX で美麗にレンダリング。
- 本文中の難解な数式・専門用語・定義・定理をクリックすると、**画面右側のスライドオーバー（Drawer/Sheet）または展開カード**が開き、以下を詳細解説：
  - **「高校生でもわかる直感解説」**（日常のたとえ話、コインや株価の例）
  - **「行間・省略ステップの完全展開」**（レポートで省略された途中計算、Leibniz則の計算過程、包絡線定理で原子の微分が消える理由など）
  - **「なぜこの定義・仮定が必要なのか」**（数学的・実践的な背景）

### 2. 【モード2】インタラクティブ数理ラボ（Interactive Visual Lab）
数式を読むだけでは掴みにくい概念を、パラメータをいじって動的に体感できるシミュレーションコンポーネント：
- **$W_1$ 距離（Wasserstein距離）の可視化**: 2つの分位点関数の間の「面積」が $W_1$ 距離であることを図解し、スライダーで形状を変えて面積の変化を体感。
- **一様配置 vs 歪み最適配置の動的比較**: スライダーでリスク水準 $\alpha$（例：0.01〜0.2）や分割数 $N$（例：8〜64）、分布（ガウス混合、Student-$t$）を切り替えると、quantile fraction $\tau_i$ が下側裾 $[0,\alpha]$ に密集していく様子をプロット表示。
- **歪み関数 $g(\tau)$ と重み $g'(\tau)$ の挙動**: CVaR歪みや正則化歪み $g_{\alpha,\lambda}$ の形状と、なぜ裾の勾配が $1/\alpha$ 倍に跳ね上がるのかを直感グラフ化。

### 3. 【モード3】口頭試問・突っ込み対策特訓（Grill Defense Trainer）
中間発表会で教授陣から突っ込まれそうな最重要論点を、**フラッシュカード / クイズ形式**で特訓できるモード：
- 「質問を見る」 $\to$ 「自分の頭で回答を組み立てる」 $\to$ 「模範回答・論理構成・突っ込まれたときの返し方・NGワードの解説を開く」。
- 必修の突っ込み例：
  1. 「実験BでIQNの方がMAEが小さいのに、なぜFQFを拡張する提案法に価値があるのか？」（回答の急所：状態ごとの境界・原子を明示保持する解釈性、最適量子化という数学的基盤、サンプリング不要な決定的評価、可視化能力）
  2. 「CVaRの時間不整合性とは何か？なぜ方策の最適性ではなく分布推定精度を測るのか？」（回答の急所：動的計画法におけるベルマン原理の不成立、Lim & Malikの指摘）
  3. 「なぜ $g'$ を掛けるだけで、歪み分布の1次元最適量子化の勾配と一致するのか？」（回答の急所：Leibniz積分則と包絡線定理の美しき一致）
  4. 「ヘビーテイル分布において一様サンプリングが破綻する本質的理由は？」（回答の急所：確率質量が集中する中央に点が偏り、損益の決定打となる裾の解像度がゼロになること）
  5. 「デルタヘッジにおいて、なぜ分散最小化ではなくCVaR最小化なのか？」（回答の急所：取引コストと離散リヘッジによるヘビーテイル損失構造）

### 4. 【モード4】定理・数式クイックリファレンス（Formula & Theorem Deck）
- 定義3.1〜3.3、命題3.1、命題4.1〜4.2、予想4.1をカード形式で一覧化。
- 各定理の「前提条件」「主張」「証明のツボ」「使われている数学的トリック」を要約。
