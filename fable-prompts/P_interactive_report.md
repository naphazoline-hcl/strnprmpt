## あなたの役割と目的
あなたは数理情報工学・分布型強化学習・数理ファイナンスの卓越した教育者兼エキスパート研究者です。
学部4年生である著者が、自身の卒業研究中間レポートの内容を**本質から完全に理解し、中間発表会や試問で教授陣から鋭い質問や突っ込みを受けた際に、自信を持って論理的・直感的に回答できるようになるための、最高品質の単一HTML学習Webアプリ（`interactive_report.html`）**をワンショット（1回の出力）で作成してください。

詳細な要件定義・画面構成・解説の粒度・追加する図解の選定は、著者の理解度最大化という目的に照らし、**すべてあなた自身がプロフェッショナルとして自律的に要件定義・設計・実装してください**。質問は禁止です。

## 実装・要件定義の必須方針（これらを網羅する要件を自律定義せよ）

### 1. レポート本文の完全再現と洗練された学術UI
- 概要から第1章〜第6章、参考文献までのレポート全文を、読みやすい論文ビューアとして美しくレイアウトする。
- 数式は KaTeX CDN を用いて美麗にレンダリングする。
- 左側または上部に固定の目次（サイドバー/TOC）を配置し、各章・節へ瞬時にジャンプできるようにする。

### 2. ホバー・クリックで開く「直感解説」「具体例」「行間解説」
レポート中のあらゆる難解な数式・定義・定理・専門用語の横に、インタラクティブな仕掛け（ツールチップ、クリック展開式アコーディオン、サイドドロワー、モーダル等）を埋め込むこと：
- **具体例とたとえ話**: 抽象的な数式に対し、「例えばサイコロやコイン、株価の例で言うとどういうことか」を噛み砕いて解説。
- **行間・省略ステップの補完**: レポートでは簡潔に済まされている数式変形（例：Leibniz則の計算過程、包絡線定理で原子側の微分が消える理由、$p=1$ Wasserstein距離の分位点表現など）を、1ステップずつ途中式付きで完全解説。
- **専門用語の即座アンカー**: quantile fraction、アトム、歪み分布、最適量子化、Voronoiセル、ヘビーテイルなどの用語をクリックすると、その場で即座に定義と意味がポップアップ。

### 3. 動的グラフ・ビジュアルシミュレーション（Chart.js / Canvas / SVG）
静的なレポートを読むだけでは理解しにくい概念について、**実際にパラメータを動かして体感できるインタラクティブ図解**を実装すること：
- **例1: $W_1$ 距離の可視化**: 2つの分位点関数の間の「面積」が $W_1$ 距離であることを図解。
- **例2: 一様配置 vs 歪み最適配置の比較**: スライダーでリスク水準 $\alpha$ や分割数 $N$ を動かすと、quantile fraction $\tau_i$ が下側裾 $[0,\alpha]$ にどのように密集するかを動的にアニメーション/プロット。
- **例3: 歪み関数 $g(\tau)$ とその導関数 $g'(\tau)$**: CVaR歪みや正則化歪み $g_{\alpha,\lambda}$ の形状と、なぜ裾の重みが $1/\alpha$ に跳ね上がるのかをグラフ表示。

### 4. 「教授からの突っ込み・試問対策」シミュレータ（Grill Defense Mode）
各章末や重要定理の箇所に、**「発表会で教員・審査員から突っ込まれそうな質問」と「それに対する満点回答」**を学べるトグル/カードを配置すること：
- 例：「なぜIQNの方が推定誤差が良いのにFQFを使うのか？」
- 例：「CVaRの時間不整合性とは何か？なぜ方策性能ではなく分布推定精度を測るのか？」
- 例：「$g'$ を掛けるだけでなぜ1次元最適量子化の勾配になるのか？」
- 例：「ヘビーテイル分布において一様サンプリングが破綻する本質的理由は？」
- 例：「デルタヘッジにおいて、なぜ分散最小化ではなくCVaR最小化が求められるのか？」

### 5. 配布・実行形式
- **完全自己完結な単一HTMLファイル**として出力すること（Tailwind CSS CDN, KaTeX CDN, Chart.js CDN などを利用）。
- 画面上部またはフローティングバーに **「HTMLダウンロード」ボタン（Blob ダウンロード）** を設置し、ローカルに1クリックで保存してオフラインでもブラウザで開けるようにすること。
- 個人情報は `【学籍番号】` `【氏名】` `【指導教員名】` `【研究室名】` の仮置きを厳守すること。
