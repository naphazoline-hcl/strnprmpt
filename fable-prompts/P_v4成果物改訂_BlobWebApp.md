## 2. 反映すべき査読指摘と修正指示（厳守）

査読講評（`v3_review_fable.txt` および `v3_review_sol.txt`）で合意された以下の指摘を**漏れなく正確に反映**した完全版を作成してください：

### ①【修正必須】表B2（共通方策交差評価）の解釈是正と過大解釈の撤回
- **問題点**: 各ネットワークは自身の greedy 方策下の分布を Bellman 標的として学習しているため、非対角セル（B0 × all-SAFE 等）には「表現誤差」だけでなく「継続方策の不一致による真値の差」が混入している。したがって「共通方策下での純粋な表現比較としては約3分の1（$1.88\to0.59$）」という読み替えは成立しない。
- **反映内容**:
  - 本文概要、貢献4、§5.2.4、§5.2.5考察、予稿§5、スライドFrame 9留意点、Q&A Q12 から「純粋な表現比較としては約3分の1」等の読み替え文を**完全に削除・撤回**する。
  - 表B2は「学習済みネットワーク出力と固定方策参照値の距離（方策不一致を含む交差評価）」として正直に位置づける。
  - §5.2.4 末尾を差し替え：「なお本交差評価には設計上の限界がある．各ネットワークは自身の CVaR-greedy 方策下の収益分布を Bellman 標的として学習しているため，参照方策と学習時の継続方策が一致するセル（B0 × all-RISKY，B1g・B2 × all-SAFE）以外では，MAE に表現誤差だけでなく継続方策の不一致による真値の差が混入する．したがって表B2は交絡を完全に分離したものではなく，B0 の 1.88 を表現誤差と解釈することはできない．交絡の厳密な分離には，方策を all-RISKY に固定した方策評価モードでの再学習が必要であり，これを第6節の課題とする．現時点で言えるのは，(a) B0 が自身の学習対象（重い裾）に対して 7.01 の誤差をもつ一方，B1g・B2 は自身の学習対象（ほぼ点質量）に対して 0.59・0.35 であること，(b) 両者の差には推定対象の難易度差が含まれること，の2点である．」

### ②【強く推奨】注意4.1（裾特異性と適応配置による二次精度）の数理的精密化
- **問題点**: 一様配置が $O(N^{-1})$ 程度（実測傾き $-0.72$〜$-1.35$）に留まる機序を「端点 $\alpha$ の誤差」とする説明は数理的に誤り（局所幅 $h$ に対し $O(h^2)=O(N^{-2})$ の振動項にすぎない）。
- **反映内容**:
  - 支配項を**「第1区間 $[0, 1/N]$ の裾特異性」**に書き換える。Student-$t_\nu$ では $\Finv(\tau)\sim -c\,\tau^{-1/\nu}$（$\nu=3$ で $\tau^{-1/3}$）であるため，第1区間の中点則誤差が $\int_0^h\tau^{-1/\nu}d\tau - h(h/2)^{-1/\nu} \propto h^{1-1/\nu} = O(N^{-(1-1/\nu)}) = O(N^{-2/3})$ となり，実測傾き $-0.72$ と整合する（第1区間だけで全誤差の85〜95\%を占める）。D1（ガウス裾）の $-1.35$ は対数的に特異性が弱いためである。
  - 一方，提案法（歪み最適配置 M2）が特異性下でも $O(N^{-2})$（傾き $-1.79$〜$-1.84$）を達成できる理由は、**$L^1$ 最適量子化の適応性**により区間幅を $w\propto ((\Finv)')^{-1/2} \propto \tau^{(1+1/\nu)/2}$ にとるため，第1区間幅が $O(N^{-\nu})$ まで劇的に縮小し，特異性の寄与が $O(N^{-2})$ 以下に抑えられるからである。
  - 実測傾きは「数値実験における経験的 log-log 回帰傾き」と明記し、無条件の理論証明と混同させない。

### ③【強く推奨】予想4.1 の正則性仮定の修正
- **問題点**: 「$\Finv$ の導関数が下側裾 $[0,\alpha]$ において正の上下界をもち」という仮定は、下側サポートが非有界（$\tau\downarrow0$ で $\Finv\to-\infty$）な本実験の全分布（D1〜D3）を除外している。
- **反映内容**: 仮定を「$\Finv$ が $(0,\alpha]$ で $C^1$ かつ $(\Finv)'\in L^1[0,\alpha]$，さらに $\tau\mapsto(\Finv)'(\tau)$ が $\tau\downarrow0$ で正則変動する分布族に対し…」に修正する。

### ④【強く推奨】B3g（FPN凍結・理論配置版）の位置づけと論理防衛の強化
- **問題点**: B3g（$0.74\pm0.33$）と B1g（$0.96\pm0.51$）は 3 シードの標本 SD 内で区別できない。「同等以上」という表現を「同等（差は 3 シードの標本 SD 内）」に改める。
- **反映内容**:
  - B3g は対抗手法ではなく、**提案理論（命題4.1・実験A M1）そのものの産物（$g$-一様配置＋$g$-中央値原子）**であると明記。FQF（7.02）や一様固定B3（4.12）からの改善は「歪み重み付き量子化理論そのもの」に帰属する。
  - toy 環境では all-SAFE 下で収益分布がほぼ点質量のため最適化の余地が小さいが、実験Aでは状態依存構造があれば最適化が事前配置を 6〜20 倍上回る。状態ごとに最適配置が異なる環境（実験C）で FPN 学習の寄与を検証する、という強い防衛線を本文§5.2.3、§5.2.5、予稿、スライドFrame 9、Q&A Q13 に明記する。

### ⑤【強く推奨】B2p の失敗機序の精密化
- **反映内容**: §5.2.5 考察の B2p 項を精密化する。「現在側の level $\tau_i$ を歪めても各 level の分位回帰の一致性は保たれるが、ターゲット側 $\tau'_j\sim g^{-1}(U)$ の等重み標本は $r+\gamma Z'$ ではなく歪み分布 $\mathcal{D}_g(r+\gamma Z')$ からの標本となるため、ネットワークは $F^{-1}_{\mathcal{D}_g Z}(\tau)=\Finv(g^{-1}(\tau))$ を学習する。読み出し $\tau\in(0,\alpha)$ では $g^{-1}_{\alpha,\lambda}(\tau)\approx\alpha\tau/(1-\lambda)$ という遥かに深い分位点を返し、CVaR を系統的に過小評価する（過度に悲観的になる）。参照方策に依らず MAE が約 4.2 で一定である（表B2）ことはこの機序と整合する。」

### 【成果物ファイルの完全保持とBlobダウンロード仕様】
Web App は外部通信なしでオフラインで完全に動作する自己完結型とし、**修正後の完全なファイル全文を内部に保持**してください：

1. **完全版成果物（v4版）の全文保持**:
   - `report_fixed_v4.tex`（本文・修正完全版）
   - `yoshi_fixed_v4.tex`（予稿・修正完全版）

2. **Blob ダウンロード機能**:
   - 画面上に各ファイルの「ダウンロードボタン」を配置し、クリック時に `new Blob([content], {type: 'text/plain;charset=utf-8'})` から `URL.createObjectURL` を生成して即座にダウンロード可能とすること。

   - 2巡目査読指摘の反映チェックリスト（表B2解釈是正、注意4.1裾特異性、予想4.1仮定、B3g論理防衛、B2p機序、表記統一など）の対応一覧表示。
   - 個人情報（【学籍番号】【氏名】【指導教員名】【研究室名】）が仮置きのまま保護されていることの確認バッジ。
   - コンパイル検証用のコマンドガイド（`platex` / `dvipdfmx` / `lualatex`）。
