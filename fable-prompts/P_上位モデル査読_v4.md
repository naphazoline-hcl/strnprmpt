# プロンプト：卒業研究中間発表成果物（v4＝2巡目査読反映版）の学術査読依頼（3巡目）

## 1. 査読の背景と目的
私は大学学部4年（情報理工学・数理科学分野）で、卒業研究の中間発表（レポート本文、A4・2段組予稿、発表5分スライド）を控えています。
テーマは**「歪み関数重み付き1-Wasserstein距離に基づくquantile fraction学習とCVaR推定誤差の低減（リスク感応型分布型強化学習）」**です。

本件は査読の**3巡目**です。2巡目（v3）の外部査読2件（Claude／GPT-Sonnet）の指摘（修正必須4点・強く推奨3点・推奨・記録訂正等）をすべて反映した**第3次改訂版（v4）**を作成しました。

2巡目から反映した主な変更：
- **表B2（共通方策交差評価）の解釈是正**：「共通方策下の純粋な表現比較で約3分の1」という読み替えを完全撤回し、「学習済み出力と固定方策参照値の距離（継続方策の不一致を含む）」として位置づけ直し。対角セルのみが交絡なしに解釈可能である旨を明記。
- **注意4.1 の全面書き換え**：一様配置が $O(N^{-1})$ 程度に留まる機序を「第1区間 $[0,1/N]$ の裾特異性（中点則誤差 $\propto h^{1-1/\nu}$）」に修正し、提案法の二次精度は適応配置による第1区間幅の急減（実測 $\tau_1\approx0.4N^{-3}$）で説明。「経験的 log-log 回帰傾き」であることを明記し断定を回避。
- **予想4.1 の正則性仮定の修正**：「$\Finv\in L^1[0,\alpha]$（$\CVaR_\alpha$ 有限）＋導関数の正則変動指数 $\beta<2$」とし、Student-$t_\nu$（$\beta=1+1/\nu$）・ガウス裾（$\beta=1$）を包含する形に。（後述のとおり、この部分は別系統の改訂案から採用・移植した。）
- **B3g の位置づけ明確化**：「同等以上」→「同等（差は 3 シードの標本 SD 内）」。B3g は対抗手法ではなく提案理論（命題4.1＋実験A M1）の産物であり、toy での改善は理論配置に帰属することを明記。防衛線（実験Aで M2 は M1 の 6〜20 倍、位置依存クラッシュ規模の低コスト中間実験案）を追加。
- **B2p の失敗機序の精密化**：「pinball 損失の重み構造の歪み」を撤回し、ターゲット側歪みサンプリング機序（等重み標本が歪み分布からの標本になり $F^{-1}(g^{-1}(\tau))$ を学習し、読み出しで CVaR を系統的過小評価）に置換。
- **生データ再検証**：収束レート回帰の出自確認（M0 傾き −0.72〜−1.27 は α=0.05・N=8〜1024 併合の公式ログ値）、一様配置の第1区間寄与の閉形式検証（D3 で 83〜95%）、B3g/B1g の方策指標再集計（polCVaR では B1g が安定・平均収益では B3g・3シードでは優劣確定不能）への Q13 訂正。
- **予備版スライドの全面再構築**（本編10＋Appendix A1〜A8）：旧版に残っていた v1 時点の数値（1.0043・「統計的有意性を検証済み」・B1 SD ±0.75 等）を除去し、表B1 完全版・表B2・設計上の限界を A5〜A7 として新設。
- そのほか：CVaR 符号規約の統一（下側 CVaR 最大化）、命題3.1 の可積分性注記（$\E|Z|<\infty$ 十分条件）、命題4.2 の適用条件 (a)〜(d) の明示、バッチ SE の定義明記、M2 は数値解である旨の初出注記、「3つのヘビーテイル分布」の表現修正、スライド Frame 9 の 3 行表への減量、Q14 新設など。

**v4 の作成にあたっての特記事項（選定・移植）**：v4 は 2 つの独立した改訂系統（GLM 版／fable 版）で作成しました。生データ照合（nsweep ログ・実験B CSV 再集計）・手元コンパイル・用語ルール検査により比較選定した結果、**GLM 版をベースに採用**し、fable 版で数学的に優れていた **予想4.1 の正則性仮定の修正** と **B2p の公平変種（読み出し $\tau$ を $g(\tau)$ に写す逆変換）の追記** を移植しました（v4.1 相当。経緯と根拠は `findings_v4.md` §6 に記載）。

## 3. 重点査読項目（3巡目）

### ① 2巡目（v3）指摘への対応が妥当か（最重要）
- **表B2 の読み替え撤回**：「継続方策の不一致を含む」との位置づけ直し、対角セル（B0×all-RISKY，B1g/B2×all-SAFE）のみが交絡なしに解釈可能という説明、方策評価モードでの再学習を展望課題とする流れは、査読指摘（撤回して正直にラベルし直すルート）を満たすか。
- **注意4.1 の機序説明**：第1区間の裾特異性（$h^{1-1/\nu}$ 律速）と実測スケーリング（$\tau_1\approx0.4N^{-3}$）に基づく説明は数理的に正当か。理論式を示さず実測スケーリングのみに留めた処理は適切か、あるいは避けられるはずの理論的ギャップを残すか。
- **予想4.1 の正則性仮定**：$\Finv\in L^1[0,\alpha]$（$\CVaR$ 有限）＋導関数の正則変動 $\beta<2$ という設定は、非有界サポート分布（Student-$t$，ガウス裾）を排除しないか。$\beta<2$ と $\CVaR_\alpha$ の有限性の整合は正しいか。
- **B3g の位置づけ**：「提案理論の産物」への再位置づけと防衛線（実験Aの 6〜20 倍・位置依存実験案）は、FPN の存在意義への突っ込み（「B3g で十分なら FPN は不要では？」）への十分な防衛か。
- **B2p の機序**：ターゲット側歪みサンプリングによる $F^{-1}(g^{-1}(\tau))$ 学習の説明は実装・理論と整合するか。公平変種（重要度重み・現在側のみ・読み出し逆変換）の列挙は十分か。

### ② 選定・移植の妥当性（`findings_v4.md` §6 の検証）
- M0 傾き −0.72〜−1.27（α=0.05，N=8〜1024 併合）への統一、Q13 の polMean／polCVaR 訂正（B3g polMean 1.598 ＞ B1g 1.365，polCVaR B1g 0.701 ＞ B3g 0.299）は生データと整合するか。
- 移植元の fable 版で発見された問題（予稿 3 ページ・M0 傾き −1.35・polMean 解釈の取り違え等）の判定は過剰でないか。

### ③ 予稿（2p）およびスライド（10フレーム）の完成度
- 予稿 2 ページに、理論・1D デモ・RL 実験（交絡の限定・B3g の位置づけを含む）が過不足なく凝縮されているか。
- スライド Frame 9 を 3 行表（FQF/B1g/IQN × 方策依存 M-est／all-SAFE 共通参照）へ減量し、詳細を予備版 A5〜A7 へ移した構成は、5 分発表として適切か。

### ④ 想定質問・防衛ラインの点検（Q14 新設回答を含む）
- 「一様配置はなぜ $O(N^{-1})$ 程度しか減衰しないのか」（Q14）の回答は、審査員の追撃（「$O(N^{-2/3})$ の 2/3 はどこから」）に耐えるか。
