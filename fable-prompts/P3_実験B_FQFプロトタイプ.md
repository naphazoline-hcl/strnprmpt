## 実装仕様

### 環境: RiskyChain-v0（自作・gymnasium API・離散行動2・コードに含める）
Pendulum-v1 は**不採用**（決定的報酬で収益分布がほぼ退化しCVaR≈平均、risk-neutralとrisk-averseの方策が一致して手法差が出ない。READMEに1行記す）。
- ホライズン H=10、位置 x∈{0,…,9}、γ=1、10ステップで終端。観測: one-hot(x) ⊕ t/H（11次元）。
- **行動と遷移（これを厳密に実装）**:
  - SAFE → r = 0.1（決定的）、位置不変。
  - RISKY → 確率 1−p(x) で成功: r = 0.5 かつ x ← x+1。確率 p(x) = 0.002·(x+1) でクラッシュ: r = −5·(1+|T₃|), T₃~Student-t(3)（ヘビーテイル損失）、**位置不変（前進しない）**。
  - エピソードは10ステップで終了。時刻 t∈{0,…,9} の到達可能状態は x∈{0,…,t} の計 **55状態**。
- 性質: 全xで E[RISKY] ≈ 0.5 − p(x)·(0.5 + 5·(1+E|T₃|)) > 0.1 → risk-neutral最適は常にRISKY。P(クラッシュ≥1回 | 常にRISKY) ≈ 10.4% > α=5% → CVaR_0.05最適な**静的**方策は「最初のkステップRISKY・以降SAFE」で、kは11個の閾値方策の総当たりで決定（プロットのoracle線）。assertで E[RISKY] > 0.1（全x）と到達可能状態55個の列挙を検証すること。

### 共通アーキテクチャ・ハイパーパラメータ（全手法完全同一）
| 構成要素 | 設定 |
|---|---|
| 分位点ネットワーク | MLP 11→256→256→(N·|A|) ReLU、N=16 |
| 最適化 | Adam lr 1e−4（分位点ネット）、Huber分位回帰損失 κ=1 |
| リプレイ/バッチ | 50k / 64、学習開始1kステップ、1 env step = 1 gradient step |
| ターゲットネット | 500ステップごとにハード更新 |
| 探索 | ε-greedy 1.0→0.05 を20kステップで線形減衰、評価時 ε=0 |
| 予算/シード | 100k env steps、seed {0,1,2} |
| 方策（共通） | CVaR_α-greedy（α=0.05）: a* = argmax_a ρ_{g_α}(Ẑ(s,a))。**全手法が行動選択にαを使う**（提案法だけが特権的知識を持たない） |

### 3手法の違い（ここだけを変える）
1. **B0 FQF（一様・ベースライン）**: FPN = 256次元特徴→線形層→softmax→cumsum。分数損失 = 一様W₁勾配（Yang et al., 2019）。FPN lr 2.5e−5。
2. **B1 歪みFQF（提案）**: B0と同一だが (a) 分数勾配に g′_{α,λ}(τᵢ) を乗じる（λ=0.05）、(b) 原子の読み出し位置を **g-中央値** g⁻¹((g(τᵢ)+g(τᵢ₊₁))/2) に変更。FPN lr は同一。
3. **B2 リスク感応IQN**: 分数は学習せず、学習時 τ~U(0,1)（両側サンプル）、cosine埋め込み64次元。行動選択時 τ~U(0,α)（CVaR歪みサンプリング、Dabney et al., 2018）。
4. **B3（任意・ストレッチ）**: 固定一様フラクションのFQF（FPNなし）。許可文献リストにないため「fixed-fraction ablation」と引用なしで記す。

### FQF分数勾配レシピ（最重要・正確に実装すること）
公式FQF実装の手法を踏襲する:
(a) 分位点ネットワーク更新時: quantile-Huber損失を分数 **.detach()** した状態で計算
(b) FPN更新時: 同じ損失を分数に勾配が流れる状態で再計算し、`taus_grad = autograd.grad(w1_loss, taus)` で分数に対する勾配を取得、`loss_fpn = (taus_grad * taus).sum()` をbackwardしてFPNへ伝播
(c) **B1の変更点はここだけ**: `loss_fpn = (taus_grad * g_prime_lam(taus) * taus).sum()`。`g_prime_lam` は正則化歪み g_{α,λ} のg′（τ≤α で (1−λ)/α、τ>α で λ）。**純粋CVaR（λ=0）は τ>α で勾配が恒等的に0になり分数が潰れるため、λ>0 を必ず使う**（READMEにこの理由を記す）
(d) 分数の非交差保証: FPN順伝播後にソート（公式実装と同じ）
(e) 原子の読み出し: B0 は中間分位点 (τᵢ₋₁+τᵢ)/2、B1 は g-中央値

### 学習・評価プロトコル
- **M-est（主指標）**: 5kステップごとにgreedy方策を凍結し、**55状態×2行動すべて**について10⁴本のベクトル化MCロールアウト（seed固定・全手法で同一の真値）で return 分布の CVaR_0.05 真値を計算、ネットワークCVaR（16原子＋純粋g_α重み Σᵢ(g_α(τᵢ₊₁)−g_α(τᵢ))·qᵢ）との MAE。oracle方策が切り替わる「意思決定に関わる状態」のみのMAEも併記。1評価 <20s。
- **M-pol**: 5kステップごとに5,000評価エピソード（ε=0）。エピソード収益のCVaR_0.05と平均。oracle静的方策を水平線で表示。
- **分数診断**: 100kステップ時点の学習済みτのヒストグラム（B0対B1、[0,α]網掛け）。
- READMEに注意書きを記す: 状態ごとのCVaR-greedy制御は静的CVaR目的と**時間整合しない**。実験Bが測るのは**推定品質**であり方策最適性ではない。
- 出力: `results/expB/*.csv`（step, seed, method, eval_type, mean_return, cvar05, cvar_est_mae, fractions_in_tail）、学習曲線図（PDF+PNG・300dpi・ラベル英語）、サマリー表（3シード mean±SD＋各シード細線）。
