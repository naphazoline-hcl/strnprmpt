- **B2p の仕様をコードに合わせて正確化**：実装では現在側 τ_i とターゲット側 τ'_j の**双方**を歪みサンプリングしており（旧記述「ベルマン標的は B2 と完全同一」は不正確），重要度重みなし・等重み1/N。Gemini指摘の「未学習領域が標的に混入」という破綻機序は実装と合わないため，機序を「pinball損失の重み構造の歪み」に修正。
- 「必然性を強く支持」「数学的に整った唯一のアプローチ」等の過大表現を撤回（本文・スライド・script・QA）。
- IQN 読み出しの16点グリッド（裾に16点全割当）の有利性を本文・QAに明記。
- 交絡分離のため**共通方策・交差評価を追加実験として実施**（`fqf_toy/eval_common_policy.py`）→ §5.2.x に新設（結果は §6.4 参照）。
- **B3（一様固定）・B3g（g-一様固定＋g-中央値・FPN凍結）の ablation を3seedで追加学習**（`agents/fqf.py` に `fixed_ginit` モードを追加）。

### 6.4 追加実験の結果（2026-09-12実施）
- **実験① N-sweep 拡張**: §6.2 のとおり（`expA/results/nsweep.csv`）。
- **実験② 共通方策交差評価**（`fqf_toy/eval_common_policy.py` → `results/expB/common_policy_eval.csv`）: 参照値を $10^5$ ロールアウト $\times$ 10 独立バッチ（バッチ SE 平均 0.011 / 0.035）で計算し，学習済み15個のネットワークを交差評価した結果：

  | 評価器 | all-SAFE (k=0) 参照 | all-RISKY (k=10) 参照 |
  | :--- | :--- | :--- |
  | B0 | 1.88±0.14 | 7.01±0.14 |
  | B1 | 0.71±0.24 | 5.78±0.30 |
  | B1g | 0.59±0.10 | 5.52±0.18 |
  | B2 | 0.35±0.05 | 5.31±0.12 |
  | B2p | 4.19±1.48 | 4.25±0.46 |

  知見: (i) B0 の M-est 7.02 の相当部分は交絡（all-RISKY 分布の難しさ）に由来し，重い裾の参照では全評価器が 4.3〜7.0 で手法間差が小さい。(ii) それでも all-SAFE 共通参照下では B1g が B0 の約3分の1（1.88→0.59）と表現自体の改善が実在。(iii) B2p はいずれの参照でも約4.2と表現全体の偏りを裏付け。k=1 の参照値は継続方策が k=0 と同一のため一致。本文 §5.2.4（表B2）・概要・貢献4・考察・Q&A Q12 に反映。
- **実験③ B3/B3g ablation**（`fqf_toy/agents/fqf.py` に `fixed_ginit`（B3g）モードを追加，100kステップ×3seed）:

  | 手法 | M-est | 限定 | polCVaR | polMean | 下側裾数 |
  | :--- | :--- | :--- | :--- | :--- | :--- |
  | B3（一様固定・算術中点・FPN凍結） | 4.12±0.35 | 9.25±0.60 | −7.28±1.95 | 3.06±0.24 | 0.00 |
  | B3g（$g$-一様固定・$g$-中央値・FPN凍結） | 0.74±0.33 | 0.66±0.52 | 0.30±0.83 | 1.60±0.40 | 15.00 |

  知見: **B3g（0.74）が B1g（0.96）と同等以上**であり，toy 環境での提案法の改善の主因は FPN の状態依存最適化ではなく **理論配置（$g$-一様配置＋$g$-中央値原子）の採用** にあること（Gemini査読 5.1 の予見どおり）を誠実に報告。方策性能面では B1g が僅かに優る（polMean 1.37 対 1.60，B3g seed0 は polCVaR −0.66 と不安定）。状態ごとに最適配置が異なる環境（実験C）で FPN 学習が効くかを検証する課題として明記。本文（表B1・§5.2.3結果・考察・§6）・スライド Frame 9・script §9/§10・Q&A Q13 に反映。なお B3g 実装は初回で backward エラー（fixed_g モードでの FPN オプティマイザ生成）により全滅し，`opt_fpn=None` 条件を修正のうえ再実行した。
