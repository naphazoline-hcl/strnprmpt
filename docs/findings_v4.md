## 2. 実数値の再検証（v4 で新たに実施した生データ照合）

### 2.1 収束レート回帰の出自確認
- `expA/results/nsweep_log.txt`（実験時の公式ログ）との照合の結果、v3 文書の傾きは **α=0.05、主格子 N∈{8..256} と拡張測定 N∈{256,512,1024} の併合データ（N=256 は主格子の値を優先）に対する回帰**であることを確認（N≥8 で完全再現）。
- 確定値：**M0 は D1 −1.271／D2 −0.825／D3 −0.721（R²=0.995/0.9996/0.998），M1 は −0.69〜−1.29，M2 は −1.804／−1.837／−1.791（R²≥0.998）**。
- v3 の「M0 −0.72〜−1.35」の −1.35 は D1・α=0.1（N=16〜256 の主格子のみ）の −1.344 との混在であった → v4 では **「−0.72〜−1.27（α=0.05，N=8〜1024 併合）」** に統一。回帰範囲の表記ゆれ（手順「N≥16」vs 注意4.1「N=8〜1024」）も「N=8〜1024 併合」に統一。
- N=1024 における M2 の誤差は 1.82×10⁻⁶（D1）〜1.68×10⁻⁵（D2）であり、参照真値の数値求根許容誤差 10⁻¹² に比べ十分大きく、精度フロア未達を確認（sol §2.4-4 への回答）。

### 2.2 一様配置の裾特異性機序（fable §3.2 の独立検証）
- D3（t₃, α=0.05）について、M0 の全 CVaR 誤差に占める第1区間 [0,1/N] の中点則誤差の割合を閉形式で計算：**N=16 で 82.8%、N=32 で 88.4%、N=64〜1024 で 93.6〜94.8%**（fable の主張「85〜95%」をほぼ確認）。
- 第1区間誤差単独の log-log 傾きは **−0.676 ≈ −(1−1/ν)=−2/3** と一致。F⁻¹(τ)·τ^{1/3} → −0.98〜−1.03（τ=10⁻²〜10⁻⁴）で F⁻¹∼−cτ^{−1/3} を確認。

### 2.3 歪み最適配置の第1区間幅スケーリング（新規検証）
- `expA/quantization_demo.py` の `solve_m2` を D3・α=0.05・N∈{16,32,64,128,256} で再実行し、M2 の第1境界を測定：**τ₁ ≈ 0.4·N⁻³**（N⁻³·τ₁ = 0.51/0.38/0.40/0.42/0.40）。
- よって第1区間の特異性寄与は w₁^{1−1/ν} ∝ N^{−(ν−1)} = N⁻² 程度に抑えられ、正則部の中点則誤差 O(N⁻²) が支配するという注意4.1 の機序が生データで裏付けられた。
- なお fable 査読が提示した「区間幅 w ∝ ((F⁻¹)')^{−1/2}」という式は、L¹ 中点則誤差の変分計算（区間誤差 ∝ (F⁻¹)'·w²、Σw=1 制約 → w ∝ ((F⁻¹)')^{−2/3}）および上記実測（N⁻³）のいずれとも整合しないため採用せず、実測スケーリングの記述のみを採用した。

### 2.4 実験Bの方策指標（Q13 数値取り違えの確認）
- `fqf_toy/results/expB/{dfqf_ginit,fixed_ginit}_seed{0,1,2}.csv` の eval_type=='policy' 行から再集計：
  - **B1g**：polMean 1.365±0.360（シード 1.721/1.375/1.000），polCVaR 0.701±0.429（0.210/0.894/1.000）
  - **B3g**：polMean 1.598±0.397（2.057/1.369/1.369），polCVaR 0.299±0.833（**−0.663**/0.780/0.780）
- したがって「方策性能面では B1g が僅かに優る（polMean 1.37 対 1.60）」は誤り（polMean は B3g のほうが高い）。v4 では「CVaR 指標（polCVaR）では B1g が安定、平均収益では B3g、3 シードでは優劣確定不能」に訂正。

### 2.5 バッチ SE の定義
- `fqf_toy/eval_common_policy.py` の `mc_truth_batches`：バッチ SE = `vals.std(0, ddof=1) / sqrt(batches)`（各状態・行動対で 10 個の独立バッチ平均の標本 SD を √10 で割った値）を全状態・行動対で平均。本文にこの定義を明記した（sol §2.5 の 3 選択肢のうち 2 番目）。
