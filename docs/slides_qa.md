## 想定質問（本問）

### Q1. IQN の歪みサンプリングとの本質的な違いは？（表示: A4）

**回答**: ご質問ありがとうございます。IQN は $\tau$ を歪んだ分布からサンプリングする、読み出し側の確率操作であります。分位点関数の表現自体は $\tau$ の全域を対象としています。一方、本研究は有限個の quantile fraction という表現力そのものを、損失の上界に基づいて下側裾に配分します。歪みをどこで扱うかが本質的に異なると考えます。

**補足**: 実装上も異なり、提案は FQF の境界勾配に $g'(\tau_i)$ を乗じるのみで、ネットワーク構造の変更は不要です（本編6枚目の定理）。

### Q2. Beyond CVaR との違いは？（表示: A4）

**回答**: Beyond CVaR は quantile fraction を固定したまま、原子の値に対してスペクトル的な重み付けを行う手法であります。本研究は区切り位置 $\tau_i$ そのものを学習し、配置を最適化します。両者は直交する設計軸でありますので、併用によりさらなる改善が期待できると考えております。

**補足**: 比較表（本編7枚目）のとおり、変更する対象が「値側」か「損失側」かの違いであり、CVaR誤差上界を扱うのは本研究のみです。

### Q3. 目的関数の重み付けは自明ではないか？（表示: A4）

**回答**: 重み付けの発想自体は自然であると認識しております。しかし我々の調査した範囲では、損失側で quantile fraction を歪み最適化した先行研究は見当たりませんでした。本研究の特徴は、CVaR 推定誤差の 1-Wasserstein 上界から目的関数と勾配の閉形式が自然に導出され、FQF への変更が係数一つで済む点にあると考えます。

**補足**: 勾配の閉形式は FQF の勾配と同じ形から $g'(\tau_i)$ 因子が付くだけであり、導出は A1 に示すライプニッツ則と包絡項の消去によります。

### Q4. 実験規模（CPU 演算）の妥当性は？（表示: A5）

**回答**: 実験Bは Ryzen 7 5825U の CPU 上で、1 run 約 35 分、100k ステップ、3 シードで実施しました。RiskyChain-v0 は小規模な環境であり、5,000 エピソードの評価で平均と標本 SD（ddof=1）を報告しております。なお、3 シードでは統計的な有意性の検定は行っておらず、シード数を 10 以上に拡張した上での bootstrap 信頼区間の報告は今後の課題と考えております。より大規模な環境への拡張は、デルタヘッジ環境とあわせて位置づけております。

**補足**: 実験Aは真の分位点関数が既知の解析的な問題であり、数値積分による高精度の基準値との比較で妥当性を確保しています（A3）。

### Q5. 実験B で IQN が MAE で優位だった理由と対策は？（表示: A5）

**回答**: 理由は 3 つ考えております。第一に、IQN は連続的な分位点補間という表現力をもち、評価時の CVaR 読み出しでは $(0,\alpha)$ 内に等間隔 16 点を割り当てられるため、裾に約 14 点しか置けない提案法より読み出し構造が有利であります。第二に、M-est の参照値は各手法の greedy 方策が作る収益分布に対するものであり、B0 は重い裾の分布、B1g/B2 はほぼ確定値の分布を推定しているため、手法間差には推定対象の難易度差が含まれております。第三に、トイ環境の単純さも IQN に有利に働いたと考えております。一方、対抗手法として学習時サンプリングを歪めた IQN（B2p）は MAE 3.42 と約 10 倍悪化しました。これはターゲット側の歪みサンプリングが、歪み分布からの標本をあたかも本来の標的であるかのように学習させる系統的バイアスの解釈と整合しております（all-RISKY・all-SAFE いずれの参照でも MAE が約 4.2 で一定）。ただし B2p は重要度補正なしの一つの実装対照であり、sampling 系一般の劣位を示すものではありません。表現再配分との公平な比較には、重要度補正あり、現在側のみ、ターゲット側のみの対照が必要で、これを今後の課題としております。トイ環境での一般的優位性は未確認ですが、デルタヘッジ環境で本質的優位性を検証してまいります。

**補足**: 提案法の特徴は、離散境界と原子の重みを明示的に制御して歪み重みに整合する再配分を行う点にあります。α を変更する場合の FPN 再学習のコストは IQN に対する限界であり、実験Cで定量比較する予定です。

## 予備質問（深掘り・追加想定）

### Q6. 上界 $L_g$ の証明の核心は？（表示: A1、必要なら A2）

**回答**: 3段階であります。第一に、歪み分布 $\mathcal{D}_g Z$ の期待値が歪みリスク尺度に一致すること、すなわち $\E[\mathcal{D}_g Z]=\int_0^1 \Finv(\tau)g'(\tau)\,d\tau=\rho_g(Z)$ であり、CVaR 歪みのとき $\rho_g(Z)=\CVaR_\alpha(Z)$ であります。第二に、期待値の差は 1-Wasserstein 距離で抑えられること $|\E X-\E Y|\le W_1(X,Y)$。第三に、変数変換 $u=g(\tau)$ により、この $W_1$ が重み $g'(\tau)$ 付きの積分 $\Lg$ に書き換わることであります。

**補足**: 最小化の対象は「CVaR 推定誤差の上界そのもの」になるため、$\Lg$ を小さくすれば CVaR の推定誤差が小さくなることが保証されます（本編5枚目の命題）。この上界自体は既知の Lipschitz 評価（Pichler 2013）の重み付き形であり、自明な上界であることを本文で明記しております。最適量子化の理論（Graf \& Luschgy）との対応は A2 を参照ください。

### Q7. 裾外の勾配が 0 で FPN は学習が進まないのでは？（表示: A1 下段の注）

**回答**: 概念上の純粋 CVaR 歪み $g_\alpha$ では裾外の $g'$ が零になるため、実装では正則化歪み $g_{\alpha,\lambda}$（$\lambda=0.05$）を用いており、裾外にも $g'=\lambda>0$ の勾配が流れる構造であります。これに加えて、FPN は累積 softmax で quantile fraction を出力するため、裾内の勾配が全ロジットに伝播し、裾外の区切りも間接的に更新されます。実際、実験Bで下側裾への集中が生じていることが確認できております。

### Q8. 原子数 $N$ はどう選ぶべきか？（表示: A3）

**回答**: 実験Aでは $N=16$ を主設定とし、$N$ を変えた感度分析を行いました。改善比 $R$ は $\alpha N\ge 2$ の領域で安定して大きく（最小 $42.3$）、log-log 傾き約 $-1.8$ で伸びることを確認しております。CVaR$_\alpha$ を対象とする場合、下側裾に 2 点以上の原子を置ける $\alpha N\ge 2$（$\alpha=0.05$ なら $N\ge 40$）が一つの目安になると考えております。

**補足**: 点数換算の考え方（歪み最適 16 点 ≈ 一様 695 点）は、同じ誤差を達成するのに必要な一様配置の原子数であり、リソース配分の利得の尺度であります。

### Q9. FPN の非凸性・局所解にはどう対処するのか？（表示: A3・A5）

**回答**: 実験Aではマルチスタート（5 種類の初期値）で最良解を採用しております。ただし Lloyd 型固定点によるクロスチェックに対して 54 設定中 8 設定で M3 が最大約 22% 良い目的関数値を示しており、すべての設定で大域最適に達した保証はありません。実用上は M2 と M3 の解の差が誤差評価に与える影響は小さいことを確認しておりますが、大域最適性の保証は今後の課題であります。実験Bの初期検討（B1）では初期化バイアスにより seed 0 で裾移動が停滞しましたが、$g$-一様初期化を施した B1g では全 3 シードで局所解が解消し、下側裾に理論通りの 14.06 個の quantile fraction が配置され、MAE 0.96 を達成しております。

**補足**: 初期配置を歪み最適配置の理論的位置（M1 相当）近くに設定することで、非凸なランドスケープにおいても安定して良い局所解へ収束させることが可能であります。

### Q10. 金融デルタヘッジ環境への適用はどう進めるのか？（表示: 本編10枚目）

**回答**: 卒業研究では Black–Scholes モデル下の ATM ヨーロピアンコールのショート＋日次リヘッジ＋取引コスト 0.1% の環境を構築し、終端損益の CVaR$_{0.05}$ を目的に提案法とリスク感応 IQN などのベースラインを定量比較します。Black–Scholes は理論上完全複製可能であるため、裾の重い損益を真にもたらす拡張として、Merton のジャンプ拡散や Heston 型確率的ボラティリティへの拡張も計画しております。あわせて、誤差比の予想の定理化と、実験Bのシード拡充（10 以上）・bootstrap 信頼区間による統計的検証を進める予定であります。

### Q11. 実験C で IQN を上回る見込みはあるのか？（表示: 本編10枚目＋A5）

**回答**: 現時点で上回るとは主張できません。優劣は実験で判定すると考えております。検証する仮説は、状態ごとに裾形状が変わり、かつ原子数・計算量を同一に制約した場合に、明示的な配置最適化が有利になるか、というものであります。機構的な根拠として、第一にヘッジ損益の下側裾は toy 環境より極端であり、有限の計算予算での解像度設計が効きやすくなること、第二に実験Aで数値最適化（M2）が事前配置（M1）を 6〜20 倍上回ったこと、すなわち分布に構造があれば最適化が効くことが挙げられます。提案法固有の利点は、CVaR が有限原子の閉形式の重み付き和として読み出せる解釈性・可視化性であります。一方で IQN の読み出しが裾に 16 点全割当できる有利さ、α 変更時の再利用性は本手法に対する限界であり、IQN が引き続き優位であれば、それも本手法の適用範囲を示す重要な結果として報告いたします。

### Q12. M-est の比較は、各手法が推定する分布が違っていて公平ではないのではないか？（表示: A7）

**回答**: ご指摘のとおりであり、本文でも交絡として明記しております。M-est の参照値は各手法の greedy 方策が作る収益分布に対して計算されるため、手法間差には表現方式の差と推定対象の難易度の差が混在しております。この検討のため共通方策（all-SAFE・all-RISKY）下での交差評価を追加実施いたしましたが、各ネットワークは自身の CVaR-greedy 方策を継続方策として学習しているため、参照方策と学習時の継続方策が一致するセル以外には「継続方策の不一致による真値の差」が混入し、本評価は交絡を完全には分離できておりません。したがって「共通方策下の純粋な表現比較で 3 分の 1」という読み替えはしておりません。現時点で確実に言えるのは、(a) all-RISKY 分布の参照では全評価器が 4.3〜7.0 の誤差をもち、重い下側裾が主要な難化要因であること、(b) B0 は自身の学習対象（重い裾）に 7.01、B1g・B2 は自身の学習対象（ほぼ点質量）に 0.59・0.35 にとどまること、の 2 点であります。厳密な分離には、行動選択・Bellman 標的・探索を all-RISKY に固定した方策評価モードでの再学習が必要であり、最終発表までに実施します。

### Q13. FPN を凍結して理論配置に固定した対照（B3g）との違いは？ B3g で十分なら FPN は不要では？（表示: A6）

**回答**: B3g は FPN を凍結し、$\tau_i$ を理論配置（$g$-一様配置）に固定して $g$-中央値原子を読み出す対照であります。結果は B3g が MAE 0.74、B1g が 0.96 と点推定値は B3g のほうが小さいものの、差は 3 シードの標本 SD 内で優劣は確定できません。この toy 環境については、現時点の結果だけを見れば固定 B3g で十分であり、FPN の追加的利得は確認できていません。本研究の現時点の成果は、まず理論配置の有効性にあります。なぜなら B3g の配置（$g$-一様配置＋$g$-中央値原子）は命題4.1と実験Aの M1 そのものであり、B0（7.02）・B3（4.12）から B3g（0.74）への改善は、FPN の有無ではなく歪み重み付き量子化の理論に帰属するからです。FPN の存在意義は、状態によって裾形状が変化し固定配置が不十分となる環境で検証すべき仮説であります。実験Aでは分布に構造がある設定で M2 が M1 を 6〜20 倍上回っており、toy 環境でもクラッシュ規模を位置依存（例：$-5(1+|T_3|)(1+x/3)$）に変更すれば状態依存性を低コストで導入でき、実験Cと合わせて検証します。なお方策性能は 3 シードでは優劣が確定できません（M-pol CVaR：B1g 0.70±0.43 と全シード正値で安定、B3g 0.30±0.83 で seed 0 は −0.66。平均収益：B3g 1.60 が B1g 1.37 を上回る）。

### Q14. 一様配置はなぜ $O(N^{-1})$ 程度しか減衰しないのか？（予備）

**回答**: 支配因は下側裾の特異性であります。本実験の分布は下側サポートが非有界で、Student-t（自由度 $\nu$）では $F^{-1}(\tau)\sim -c\,\tau^{-1/\nu}$ と発散します。一様配置ではこの特異性を含む第 1 区間 $[0,1/N]$ の中点則誤差が $h^{1-1/\nu}$ に比例し、CVaR 誤差は $O(N^{-(1-1/\nu)})$ に律速されます。実際、D3（$\nu=3$）では第 1 区間だけで全誤差の 83〜95％を説明でき、その傾き −0.68 は理論値 $-(1-1/3)=-2/3$ と一致しております。一方、歪み最適配置は適応性により第 1 区間幅を実測で $\tau_1\approx0.4N^{-3}$ まで縮めるため特異性の寄与を回避でき、正則部の中点則誤差 $O(N^{-2})$ が支配となり実測傾き −1.79〜−1.84 と整合いたします。

**補足**: 「$O(N^{-2/3})$ の 2/3 はどこから」と問われた場合は「$1-1/\nu$、$t_3$ の裾指数から」と即答する。
