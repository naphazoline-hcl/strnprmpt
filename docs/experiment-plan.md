## 0. 概要

**アイデア.** FQF (Yang et al., 2019) は一様重みの 1-Wasserstein 距離 W₁(Z, Ẑ_N) を最小化して分位フラクション τ₁<…<τ_{N−1} を学習する。本研究では FPN の目的関数を歪み重み付き距離

    L_g(τ) = ∫₀¹ |F⁻¹(u) − F̂⁻¹(u)| g′(u) du = W₁(g_#Z, g_#Ẑ_N)

に置き換える。これによりフラクションは歪み後の分布 g_#Z に対する 1 次元最適量子化問題 (Graf & Luschgy, 2000) の解となる。任意の歪みリスク尺度 ρ_g(Z)=∫₀¹F⁻¹(τ)dg(τ) について |ρ_g(Z) − ρ_g(Ẑ)| ≤ W₁(g_#Z, g_#Ẑ) が成り立つため、フラクションは g′ が大きい領域、CVaR_α の場合は下側尾 [0, α] に集中する。

**仮説.**
- H1（量子化・実験A）: N を固定したとき、αN ≥ 2 の領域で、歪み最適フラクションは一様フラクションに対して |CVaR_α(Ẑ_N) − CVaR_α(Z)| をオーダー 1/α 倍改善する。
- H2（RL・実験B）: 稀少なヘビーテイル損失を持つ toy MDP において、歪み FQF は同一予算の FQF およびリスク感応 IQN よりも収益分布の CVaR_α を正確に推定し、かつリスク回避方策の性能を劣化させない。

**記法と規約.** Z は P&L（大きいほど良い）、リスクは下側尾。CVaR_α(Z) = (1/α)∫₀^α F⁻¹(u)du = ρ_{g_α}(Z), g_α(τ)=min(τ/α,1)。正則化歪み g_{α,λ}(τ) = (1−λ)g_α(τ) + λτ、既定 λ=0.05（至る所で g′ ≥ λ > 0 となり α 以上の平坦領域を回避）。フラクション 0=τ₀<τ₁<…<τ_N=1、原子 q_i = F⁻¹(τ̂_i)、重み τ_{i+1}−τ_i, i=0..N−1。原子位置はセルの **g-中央値** τ̂_i = g⁻¹((g(τ_i)+g(τ_{i+1}))/2)（一様 g では算術中点に一致＝FQF）。この選択でフラクション勾配は厳密になる:

    ∂L_g/∂τ_i = g′(τ_i) · [ 2F⁻¹(τ_i) − F⁻¹(τ̂_i) − F⁻¹(τ̂_{i−1}) ],   i=1..N−1.

評価には常に（正則化していない）純粋な g_α を用いる: CVaR_α(Ẑ_N) = Σ_i (g_α(τ_{i+1}) − g_α(τ_i)) q_i。

## 1. 実験A — 歪み分布の 1 次元最適量子化（必須）

### 1.1 対象分布（いずれも P&L、下側尾がヘビー）
| ID | Z | パラメータ | 備考 |
|----|---|-----------|------|
| D1 | ガウス混合 | 0.9·N(0,1) + 0.1·N(−4,1) | 二峰性の損失クラスタ |
| D2 | 負の対数正規 | Z = e^{σ²/2} − exp(σξ), ξ~N(0,1), σ=1 | 平均 0。元計画では下側尾が軽かったため符号反転 |
| D3 | Student-t | ν=3 | 対称、3 次モーメント無限大 |
| D4（任意） | ガウス | N(0,1) | ヘビーテイルなしの対照 |

### 1.2 歪み関数
- CVaR: g_{α,λ}, α ∈ {0.01, 0.05, 0.1}, λ = 0.05（λ ∈ {0, 0.01, 0.2} のアブレーションは D1 のみ）。
- Wang 変換（任意・頑健性確認）: g_η(τ) = Φ(Φ⁻¹(τ) + η), η = 1.0。g′ は滑らかで正。

### 1.3 手法（フラクション配置）。全手法で同一のオラクル F⁻¹ と同一の N ∈ {8, 16, 32, 64} を使用（α=0.01 の H1 検証の裾として N ∈ {128, 256} を任意追加）。
- **M0 一様（FQF）:** τ_i = i/N、算術中点。
- **M1 g-uniform（対照: 尾部事前知識のみ・最適化なし）:** τ_i = g⁻¹(i/N)。すなわち FQF の一様グリッドを g_#Z に適用したもの。
- **M2 歪み最適（提案）:** argmin_τ L_g(τ)。θ ∈ ℝ^N に対する L-BFGS-B、τ = cumsum(softmax(θ))（構成的に単調かつ (0,1) 内、ソート不要）。初期値: M1 由来の θ と 4 つの Dirichlet(α=5·1) 摂動の計 5 スタート、L_g 最小の解を採用。解析勾配（上式を softmax のヤコビアンで連鎖）。maxiter 500, gtol 1e−10。初期点で中心差分と勾配を照合（相対誤差 < 1e−4 を要求。当初 1e−5 だったが α=0.01 構成で有限差分のノイズ床 ~6e−5 に達するため緩和。α=0.05 では実測 4e−7 で照合済み）。
- **M3 Lloyd 型固定点（クロスチェック）:** (i) 原子 ← セルの g-中央値、(ii) 境界 τ_i ← 2F⁻¹(τ_i) = F⁻¹(τ̂_i)+F⁻¹(τ̂_{i−1}) を解く（F⁻¹(τ_i) が隣接原子の中点）を交互に 200 回反復。M2 と一致すること: |L_g(M2) − L_g(M3)| < 1e−6。

### 1.4 真値（解析的。MC はクロスチェックのみ）
部分期待値 PE(a,b) = E[Z·1{a<Z≤b}] を用いる。F⁻¹ は `scipy.stats.*.ppf`（D2, D3）または混合 CDF に対する `brentq`（D1, xtol 1e−12）:
- ガウス成分 N(μ,σ²): PE = μ(Φ(b′)−Φ(a′)) − σ(φ(b′)−φ(a′)), b′=(b−μ)/σ。混合: Σ_k w_k PE_k。
- Student-t (ν>1): ∫_a^b t f_ν(t)dt = [ −(ν+t²)/(ν−1) · f_ν(t) ]_a^b。
- 対数正規 Y=exp(σξ): E[Y·1{Y≤y}] = e^{σ²/2} Φ((ln y − σ²)/σ)。符号反転で Z = e^{σ²/2} − Y に写す。
- 真の CVaR_α(Z) = (1/α) · PE(−∞, F⁻¹(α))。
- クロスチェック: 10⁷ サンプル、seed 0、経験 CVaR。|解析 − MC| < 3·SE(MC) を要求。付録表で報告。

### 1.5 L_g の厳密評価（台形則グリッドは使わない）
CVaR 歪みでは g′ が区分定数なので、α を跨ぐセル [τ_i, τ_{i+1}] は α で分割する。重み c が一定の区間 [a,b] と原子 q = F⁻¹(m) に対し、m′ = clip(m, a, b) として

    ∫_a^b |F⁻¹(u) − q| du = [ (m′−a)·q − PE(F⁻¹(a), F⁻¹(m′)) ] + [ PE(F⁻¹(m′), F⁻¹(b)) − (b−m′)·q ],

L_g = Σ_区間 c · (上記積分)。F⁻¹ の単調性により厳密。Wang 変換（滑らかな g′）ではセルあたり u 上の 64 点ガウス–ルジャンドル求積を用い、10⁶ 点台形則と一度だけ照合（相対誤差 < 1e−6）。

### 1.6 評価指標
- e = |CVaR_α(Ẑ_N) − CVaR_α(Z)|; 相対誤差 e/|CVaR_α(Z)|。
- 改善比 R = e_M0 / e_M2（最適化の寄与として e_M1 / e_M2 も併記）。
- 手法ごとの診断: L_g、一様 W₁(Z, Ẑ_N)（M2 が犠牲にするもの）、[0, α] 内のフラクション数。
- N-equivalence: e_M0(N′) ≤ e_M2(N) を満たす最小の N′ ∈ {8,…,1024}（2 のべきで探索後、二分法）。
- 経験収束レート: N ≥ 16 で log e 対 log N の OLS 傾き（≈ −1 を期待、Graf & Luschgy 2000）。

### 1.7 有限サンプル変種 A-fs（誤差バーが意味を持つ設定）
F⁻¹ を n ∈ {10³, 10⁴, 10⁵} の i.i.d. サンプル（seed 0–9）の経験分位関数で置き換える。M2 は経験 F⁻¹ 上で最適化（M0 はデータ不要）し、Ẑ_N の CVaR を解析真値と比較する。シードにわたる平均 ± SD と、e_M2 < e_M0 となったシードの割合を報告。グリッド: D1–D3 × α ∈ {0.01, 0.05} × N ∈ {16, 64}。

### 1.8 計算予算（CPU、8 スレッド）

### 1.10 擬似コード（30 行以内）
```
def solve_fractions(dist, g, N, seeds):            # dist: ppf, PE (partial expectation)
    def unpack(theta):                              # monotone fractions in (0,1)
        gaps = softmax(theta); tau = concat([0], cumsum(gaps)); tau[-1] = 1
        that = g.inv(0.5 * (g(tau[:-1]) + g(tau[1:])))          # g-median atoms
        return tau, that
    def objective(theta):
        tau, that = unpack(theta); L = 0
        for i in range(N):                          # exact cell integral, split at alpha
            for (a, b, c) in g.pieces(tau[i], tau[i+1]):        # constant weight c on [a,b]
                m = clip(that[i], a, b); q = dist.ppf(that[i])
                L += c * ((m - a) * q - dist.PE(dist.ppf(a), dist.ppf(m))
                          + dist.PE(dist.ppf(m), dist.ppf(b)) - (b - m) * q)
        return L
    def gradient(theta):
        tau, that = unpack(theta); F = dist.ppf
        dL_dtau = g.deriv(tau[1:-1]) * (2 * F(tau[1:-1]) - F(that[1:]) - F(that[:-1]))
        return softmax_cumsum_jacobian(theta).T @ pad(dL_dtau)   # chain rule to theta
    best = None
    for s in seeds:                                 # multi-start: M1 init + Dirichlet perturbations
        theta0 = log(diff(g.inv(linspace(0, 1, N + 1)))) + (0 if s == 0 else dirichlet_noise(s))
        res = minimize(objective, theta0, jac=gradient, method="L-BFGS-B", options=dict(maxiter=500, gtol=1e-10))
        best = res if best is None or res.fun < best.fun else best
    return unpack(best.x)

def cvar_hat(tau, that, dist, alpha):               # exact CVaR of the discrete law, pure g_alpha
    g = lambda t: minimum(t / alpha, 1.0)
    return sum((g(tau[1:]) - g(tau[:-1])) * dist.ppf(that))

for dist, alpha, N in grid:                         # M0/M1 are closed-form; M2 via solve_fractions
    truth = dist.PE(-inf, dist.ppf(alpha)) / alpha
    errors[dist, alpha, N] = {m: abs(cvar_hat(*place(m), dist, alpha) - truth) for m in ["M0", "M1", "M2"]}
```

## 2. 実験B — Toy RL プロトタイプ（できれば）

### 2.1 環境: `RiskyChain-v0`（自作、gymnasium API、離散行動）
Pendulum-v1 は不採用: 連続行動（FQF は DQN 系手法）かつ決定的報酬のため収益分布がほぼ退化し、CVaR ≈ 平均となってリスク回避方策と risk-neutral 方策が一致する。
- ホライズン H = 10、位置 x ∈ {0,…,9}、各ステップで x ← x+1、10 ステップで終了。観測: one-hot(x) ⊕ t/H（11 次元）。γ = 1。
- 行動と遷移: SAFE → r = 0.1（決定的）、位置不変。RISKY → 確率 1 − p(x) で成功（r = 0.5、x ← x+1）、確率 p(x) = 0.002·(x+1) でクラッシュ（r = −5·(1 + |T₃|), T₃ ~ Student-t(3)（ヘビーテイル損失）、位置不変＝前進しない）。したがって時刻 t ∈ {0,…,9} に到達可能な状態は x ∈ {0,…,t} の 1+2+…+10 = 55 個（§2.3 の MC 真値はこの 55 状態 × 2 行動）。
- 性質: 全 x で E[RISKY] ≈ 0.5 − p(x)·(0.5 + 5·(1+E|T₃|)) > 0.1 → risk-neutral 最適は常に RISKY。P(クラッシュ発生 | 常に RISKY) ≈ 10.4% > α = 5% → CVaR_0.05 最適な静的方策は「最初の k ステップだけ RISKY、以降 SAFE」で、k は 11 個の閾値方策の総当たりで決定（図中の oracle 線）。方策が状態依存になり非自明。
- 推定誤差の真値: 方策を固定し、到達可能な 55 個の (x,t) 状態 × 行動ごとに 10⁴ 本のベクトル化ロールアウト MC → CVaR_α(s,a)。1 評価あたり < 20 s。

- **B0 FQF:** FPN = 256 次元特徴に対する線形層 → softmax → cumsum。フラクション損失 = 一様 W₁ 勾配 (Yang et al., 2019)。FPN の Adam lr 2.5e−5。エントロピー係数 0（フラクションが潰れる場合は 1e−3 でアブレーション）。
- **B1 歪み FQF（提案）:** B0 と同じだが、フラクション勾配に g′_{α,λ}(τ_i) を乗じ、原子を g-中央値に置く。λ = 0.05。FPN lr は同一。
- **B2 リスク感応 IQN (Dabney et al., 2018):** 学習では 16 個の τ ~ U(0,1) をサンプル（両側）、cosine 埋め込み次元 64。行動選択では 16 個の τ ~ U(0, α)（CVaR 歪みサンプリング）。
- **B3（任意アブレーション）:** 固定一様フラクションの FQF（FPN なし）。[要確認: QR-DQN に対応するが許可文献リストにないため、引用なしで「固定フラクションのアブレーション」と記述する。]
公平性: シード、予算、ネットワーク幅、評価プロトコルを同一にする。全エージェントが行動選択に α を用いるため、特定のエージェントだけが特権的知識を持つことはない。

- **フラクション診断:** 100k ステップ時点で全評価状態にわたる学習済み τ のヒストグラム（B0 対 B1）。

## 3. 実験C — Black–Scholes 下のデルタヘッジ（中間発表後・計画のみ）
ATM ヨーロピアンコール 1 枚をショート（K = S₀ = 100, T = 30 営業日, Δt = 1/252, σ = 0.2, r = 0）し、離散ヘッジ比率 a ∈ {0, 0.1, …, 1.0}（11 行動）で日次リヘッジする。取引コストは売買想定元本の 0.1%（比例）。ステップ報酬 = 日次 P&L 増分、終端報酬にオプションのペイオフを含める。状態 = (S_t/K, 満期までの時間, 現在のヘッジ比率)。目的: 終端 P&L の CVaR_0.05 の最大化。ベースライン: 解析 BS デルタヘッジ（同一コスト・同一離散化）、FQF、リスク感応 IQN。提案: 歪み FQF。指標: 10⁴ 本のホールドアウトパスにおける終端 P&L の経験 CVaR_0.05 と平均、および固定状態での 10⁴ パス MC に対する推定 MAE。真にヘビーテイルを生むジャンプリスク付きの副次環境 [要確認: Merton ジャンプ拡散。許可リスト外]。予算: 1 ランあたり 500k ステップ、CPU で ≈ 1–2 時間、各エージェント 3 シード。動機と Moghimi & Ku (2025)、Zhang (2025) との関連: ヘッジ損失に対する尾部集中表現。CVaR 最適化の理論は Rockafellar & Uryasev (2000) に従う。

## 7. 再現性
```
repo/
  expA/  distributions.py  objective.py  solve.py  run_grid.py  run_fs.py
  expB/  risky_chain.py  agents/{fqf.py, dfqf.py, iqn.py}  train.py  evaluate.py
  figures/  make_figures.py
  results/  expA/*.csv  expB/*.csv
  Makefile   (targets: expA, expA-fs, expB, figures)
```
- シード: 実験A 解析設定 — 不要（決定論的）。マルチスタート seed 0–4。A-fs seed 0–9。MC クロスチェック seed 0。実験B は環境、リプレイ、ネットワーク初期化、評価に seed {0,1,2}（構成要素ごとに独立の `numpy.random.Generator`）。
- 環境: Python 3.11, numpy, scipy, torch (CPU build), gymnasium, matplotlib。正確なバージョン固定値は初回実行時に `requirements.txt` に記録 [要確認: 固定値]。
- 全 CSV 行に以下を記録: 分布, α, λ, N, 手法, seed, e, L_g, 一様 W₁, 実時間, git commit hash。
