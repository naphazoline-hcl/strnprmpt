### 2. 研究背景 [0:30-1:00]
通常の強化学習は期待値を最大化しますが、期待値は分布を単一の平均値に集約するため、破産やクラッシュのような稀な大損失を個別には評価・制御できません。 [alertblock を指す] そこで、損失分布全体を学習する分布型強化学習を用います。実装上は分位点関数を有限個の原子で近似します。

[スライド送り]

### 3. CVaR [1:00-1:30]
目標とするリスク尺度は CVaR です。 [数式を強調] これは最悪 $\alpha$ の範囲に条件付けた損益の期待値です。 [図の赤い領域を指す] 歪み関数 $g$ を用いると重み付き積分として表せます。本質的な着眼点は、CVaR の推定精度が下側裾 $[0,\alpha]$ の近似精度のみで決まるという点です。

[スライド送り]

### 4. FQF と課題 [1:30-2:00]
既存の FQF は quantile fraction を学習可能にしますが、 [図を指す] 目的関数が一様重みの 1-Wasserstein 距離であるため、下側裾への集中を直接には促しません。 [alertblock を指す] 例えば $\alpha=0.05, N=16$ では下側裾内の内部境界は 0 個となり、CVaR 推定誤差が生じやすくなります。

[スライド送り]

### 5. 理論的着想 [2:00-2:30]
そこで本研究は次の命題に着目します。 [数式を強調] CVaR の推定誤差は、歪み分布どうしの 1-Wasserstein 距離 $L_g$ で上から抑えられます。ゆえに FQF の目的関数を一様重みから $L_g$ に置き換えることで、CVaR 誤差上界に整合した目的指向量子化として解くことができます。 [図を指す]

[スライド送り]

### 6. 提案手法の核心 [2:30-3:00]
提案の中心となる命題を示します。 [数式を強調] 各区間の代表原子を $g$-中央値にとると、境界勾配は FQF の勾配に $g'(\tau_i)$ を乗じる閉形式となります。実装上の変更は $g$-中央値化と $g'$ 乗算の2点のみで、plug-in 擬似勾配として簡潔に実装できます。

## 質疑応答スクリプト（3分・各30〜45秒）
※質疑応答では、予備版 `slides_concise.pdf` の該当 Appendix を表示して回答します。

### Q1. IQN の歪みサンプリングとの本質的な違いは？（Appendix A4 を表示）
[A4 へ移動] ご質問ありがとうございます。IQN は $\tau$ を歪んだ分布からサンプリングする、読み出し側の確率操作です。分位点関数の表現自体は $\tau$ の全域を一様に扱っています。一方、本研究は有限個の quantile fraction という表現リソースそのものを、損失の上界に基づいて下側裾に配分します。歪みをどこで扱うかが本質的に異なると考えます。

### Q2. Beyond CVaR との違いは？（Appendix A4 を表示）
[A4 の 2 番目のブロックを指す] Beyond CVaR は quantile fraction を固定したまま、原子の値に対してスペクトル的な重み付けを行う手法です。本研究は区切り位置 $\tau_i$ そのものを学習し、配置を最適化します。両者は直交する設計軸ですので、併用によりさらなる改善が期待できると考えております。

### Q3. 目的関数の重み付けは自明ではないか？（Appendix A4 を表示）
[A4 の 3 番目のブロックを指す] 重み付けの発想自体は自然ですが、調査した範囲では損失側で quantile fraction を歪み最適化した先行研究は見当たりませんでした。本研究の特徴は、CVaR 推定誤差の 1-Wasserstein 上界から閉形式が自然に導出され、主な変更が代表水準の $g$-中央値化と勾配への $g'$ 乗算の2点で済む点にあると考えます。

### Q4. 実験規模（CPU 演算）の妥当性は？（Appendix A5 を表示）
[A5 へ移動] 実験Bは Ryzen 7 5825U の CPU 上で、1試行あたり約35分、100kステップ、3シードで実施しました。RiskyChain は小規模環境であり、5,000エピソードの評価で平均と標本SDを報告しています。なお3シードでは有意性の検定は行っておらず、シード10以上への拡張と bootstrap 信頼区間は今後の課題です。

### Q5. 実験Bで IQN が優位だった理由と対策は？（Appendix A5 を表示）
[A5 の 2 番目のブロックを指す] 理由は2点あります。第一に IQN は評価時に下側裾へ16点すべてを割り当てられる読み出し構造をもつ点です。第二に、本トイ環境が単純で状態適応性の必要性が低かった点です。また、M-est には継続方策の違いに伴う難易度差も含まれています。今後は固定方策下での再学習や、金融デルタヘッジ環境において真の表現能力を比較してまいります。
