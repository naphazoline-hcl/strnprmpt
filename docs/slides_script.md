### 2. 研究背景 [0:30-1:00]
通常の強化学習は、リターンの期待値を最大化します。しかし破産やクラッシュのような、確率は小さく損失が大きい事象は、期待値にはわずかしか寄与しません。したがって下側リスクを制御できません。 [alertblock を指す] そこで、リターンを確率変数として分布全体を学習する分布型強化学習が必要となります。実装上は分位点関数を有限個の原子で近似します。

[スライド送り]

### 3. CVaR [1:00-1:30]
本研究の目標リスク尺度は CVaR であります。 [数式を強調] これは分位点関数を下側 $\alpha$ の範囲で積分した、最悪 $\alpha$ の事象に条件付けた期待リターンです。 [図の赤い領域を指す] 歪み関数 $g$ を用いると、密度 $g'$ による重み付き積分として書けます。重要な点は、CVaR の推定精度が下側裾の近似精度だけで決まることです。

[スライド送り]

### 4. FQF と課題 [1:30-2:00]
既存手法 FQF は、累積確率軸の区切り位置である quantile fraction をネットワークで適応的に学習する代表的枠組みです。 [図を指す] ただし目的関数は一様重みの 1-Wasserstein 距離であるため、区切りは確率質量に比例して配置されます。 [alertblock を指す] $\alpha$ が 0.05、$N$ が 16 では下側裾に約 0.8 個しか置かれず、CVaR 推定誤差が生じやすいのです。

[スライド送り]

### 5. 理論的着想 [2:00-2:30]
そこで本研究は、次の命題から出発します。 [数式を強調] CVaR の推定誤差は、歪み分布どうしの 1-Wasserstein 距離 $L_g$ で上から抑えられます。証明は、歪み分布の期待値が CVaR に一致することと、期待値の差が $W_1$ 以下であることに帰着します。ゆえに FQF の目的関数を $L_g$ に置き換えれば、誤差上界そのものを最小化することになります。 [図を指す]

[スライド送り]

### 6. 提案定理 [2:30-3:00]
提案の中心となる定理を示します。 [数式を強調] 原子を $g$-中央値にとると、quantile fraction に関する勾配は、FQF の勾配に $g'(\tau_i)$ を乗じた閉形式で与えられます。$g'$ は下側裾で $1/\alpha$、裾外で 0 でありますから、表現力が下側裾へ自然に配分されます。実装変更は係数を掛けるだけで、原子の更新は従来通りの分位点回帰です。

[スライド送り]

### 7. 位置づけ [3:00-3:30]
先行研究との位置づけを整理します。 [表を指す] IQN はサンプリング側、Beyond CVaR は値側の重み付け、Tail-Safe は安全制約側の設計であり、quantile fraction は固定または非学習です。FQF は損失側ですが一様重みです。我々の調査した範囲では、損失側で誤差上界に基づき区切り位置自体を最適化する点が、本研究の新たなアプローチであります。

[スライド送り]

### 8. 実験A [3:30-4:00]
実験Aでは、真の分位点関数が既知の3分布で最適配置を比較しました。 [左図を指す] 歪み最適配置は内部 15 個の quantile fraction のうち 13 個を下側裾に置きます。 [右の表を指す] CVaR 誤差の改善比 $R$ は 97.9、52.4、39.6 で、判定基準 $R\ge2$ を全分布で満たしました。歪み最適の 16 点は、一様配置の約 695 点に相当します。

### 9. 実験B [4:00-4:30]
実験Bでは、クラッシュ損失を持つ RiskyChain-v0 で学習を行いました。 [図を指す] CVaR 推定の平均絶対誤差は、FQF の 7.02 に対し、$g$-一様初期化を導入した提案手法 B1g で 0.96 と、約 7 分の 1 に低減しました。 [表を指す] 下側裾の quantile fraction も理論通りの 14.06 個に達し、局所解を解消しました。また学習時サンプリングを歪めた IQN は 3.42 と悪化したことから、表現側の再配分の本質性を確認しました。一方、トイ環境では連続補間を行うリスク感応IQNが 0.36 と最良であり、一般的優位性は未確認であります。

## 質疑応答スクリプト（3分・各30〜45秒）

### Q1. IQN の歪みサンプリングとの本質的な違いは？（A4 を表示）
[Appendix A4 へ移動] ご質問ありがとうございます。IQN は $\tau$ を歪んだ分布からサンプリングする、読み出し側の確率操作であります。分位点関数の表現自体は $\tau$ の全域を対象としています。一方、本研究は有限個の quantile fraction という表現力そのものを、損失の上界に基づいて下側裾に配分します。歪みをどこで扱うかが本質的に異なると考えます。

### Q2. Beyond CVaR との違いは？（A4 を表示）
[A4 の 2 番目のブロックを指す] Beyond CVaR は quantile fraction を固定したまま、原子の値に対してスペクトル的な重み付けを行う手法であります。本研究は区切り位置 $\tau_i$ そのものを学習し、配置を最適化します。両者は直交する設計軸でありますので、併用によりさらなる改善が期待できると考えております。

### Q3. 目的関数の重み付けは自明ではないか？（A4 を表示）
[A4 の 3 番目のブロックを指す] 重み付けの発想自体は自然であると認識しております。しかし我々の調査した範囲では、損失側で quantile fraction を歪み最適化した先行研究は見当たりませんでした。本研究の特徴は、CVaR 推定誤差の 1-Wasserstein 上界から目的関数と勾配の閉形式が自然に導出され、FQF への変更が係数一つで済む点にあると考えます。

### Q4. 実験規模（CPU 演算）の妥当性は？（A5 を表示）
[Appendix A5 へ移動] 実験Bは Ryzen 7 5825U の CPU 上で、1 run 約 35 分、100k ステップ、3 シードで実施しました。RiskyChain-v0 は小規模な環境であり、数千エピソードにわたる評価で平均と標準偏差を報告し、統計的有意性を確認しております。より大規模な環境への拡張は、デルタヘッジ環境とあわせて今後の課題と位置づけております。

### Q5. 実験Bで IQN が優位だった理由と対策は？（A5 を表示）
[A5 の 2 番目のブロックを指す] トイ環境では連続的な分位点補間を行う IQN の表現力が極めて有利に働いたと考えております。一方、対抗手法として学習時サンプリングを歪めた IQN（B2p）を検証したところ、MAE は 3.42 と約10倍悪化しました。これにより、提案法のように表現（quantile fraction）側の最適量子化として再配分する定式化が本質的であると実証できました。また初期化改善（B1g）により FQF 比で約 7 分の 1（0.96）まで誤差を低減できております。トイ環境での一般的優位性は未確認ですが、金融デルタヘッジ環境において離散表現の真の優位性を検証してまいります。
